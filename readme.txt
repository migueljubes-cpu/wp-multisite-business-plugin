# WP Multisite Business Plugin

Plugin avanzado para WordPress Multisite desarrollado para la gestión empresarial y automatización de tareas.

## Funcionalidades

- Dashboard centralizado
- Gestión de clientes
- Gestión de pedidos
- Marketing
- Integración Gmail API
- Integración Google Analytics 4
- Integración Search Console
- Integración Claude AI
- Integración Odoo
- Gestión de envíos
- Sistema de notas internas
- Integración Cloudflare

## Tecnologías utilizadas

- PHP
- JavaScript
- CSS
- WordPress Multisite
- REST API
- Google APIs
- Claude AI

## Estructura del proyecto

```text
api/
assets/
core/
modules/
templates/
```

## Instalación

1. Copiar el plugin en:

```
wp-content/plugins/
```

2. Activar desde el panel de WordPress.

3. Configurar las credenciales requeridas.
